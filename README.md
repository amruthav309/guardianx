# 🛡️ GuardianX

GuardianX is an AI-powered Digital Safety Platform that protects users from phishing emails, scam SMS messages, malicious URLs, weak passwords, and online scams.

---

## Features

- Email Phishing Detection
- Scam SMS Detection
- URL Scanner
- Password Strength Checker
- Scan History
- Cyber Safety Dashboard
- AI Threat Explanation
- Analytics
